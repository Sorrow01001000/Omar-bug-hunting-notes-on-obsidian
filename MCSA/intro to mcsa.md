1-Active directory
ده حاجه بتتعمل لما بنعمل windows server بتبقي داتا بيز صغيره فيها كل معلومات الشبكه , users عدد الاجهزه وما الي ذلك.

2-Group policy 
الصلحيات اليقدر يعملها ال user والتحكم في الاجهزه زي اني اقفل مدخل ال usb او اقفل حاجات معينه علي الويندوز زي الالعاب او ال run وما الي ذلك.

3-File server
بنستخدمه عشان نعمل sharing لو الusers محتاجين ينقلو باينات بينهم وبين بعضهم فا بنعمل file shared بين الusers الانا محددهم وليكن ال hr كلهم عشان يبدلو بيانات وفيلات مع بعض دول الحاجه لاستخدام فلاشه.

![[Pasted image 20250815175226.png]]
4- DHCP 
غير انه بيوزع ips علي الاجهزه بس بل كمان بيوزع configurations للشبكه زي ال subnet mask و gateway وهكذا.

![[Pasted image 20250815175441.png]]
5- DNS 
دلوقتي الاجهزه عايزه تكلم test.local و ده domain name بتاع ال windows server الاجهزه مش بتفهم ال domain name بس بتفهم ips فا عايزين حاجه تحول ده ل ده فا هيا دي فايده ال dns.

![[Pasted image 20250815175740.png]]
6- Print server
دلوقتي عندي طابعه فا بدل ما اوصلها علي جهاز واحد وهوا اليطبع وكدا بوصلها علي ال windows server وبتحكم فيها عن طريق ال print server وده بيتيح ليا انا اتحكم في الطابعه واخلي مين الاجهزه اليستخدموها و يطبعو ابيض واسود بس ولا الوان عشان التكلفه وكمان ممكن احدد وقت معين للطباعه امتي يطبعو يعني الساعه من كام لكام.

![[Pasted image 20250815175936.png]]
7- Windows server update service
دلوقتي عندي علي الشركه 150 جهاز عايزين ابديت دلوقتي كل الاجهزه دي طلعت علي النت مره واحده فا طبيعي النت اي الهيحصل فيها هيتاكل وال bandwidth بتاعتك بح فا دلوقتي فايده الشيء ده انه هوا بيطلع يجيب ال update من Microsoft update servers وبعد كدا اوزع انا بقا الابديتس بمعرفتي علي الاجهزه وهكذا.

![[Pasted image 20250815180304.png]]
8- windows deployment service
دلوقتي في الطبيعي لو انا عايز اسطب ويندوز علي جهاز او كدا فا بحتاج dvd او usb وكدا فا لا الشيء ده بيخلينا نسطب الويندوز بس عن طريق ال windows server ذات نفسه.

![[Pasted image 20250815180550.png]]
9- hyper - v 
ده عشان لو عايز تشغل virtual machines علي الاجهزه والتحكم بيبقي من الwindows server.

![[Pasted image 20250815180657.png]]
10- Disaster Recovery
من اسمه يعني زي ال backup plan بتاعتي وكدا فا مثلا انا عندي main domain controller لو حصله حاجه فا لازم يبقي ليه backup اسمه additional domain controller.
